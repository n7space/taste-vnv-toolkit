Verification Toolkit
MBEP-FUN-230; SpaceCreator shall support the execution of automated verification scripts from external verification tools.; ;
MBEP-FUN-360; SpaceCreator shall provide the capability to view the results generated by external tools.; ;  
MBEP-CFG-90; SpaceCreator shall provide the capability to configure the set of external tools to be used.; User may want to be able to set a specific version of the used toolchain, e.g., switch between gdb and arm-none-eabi-gdb.; Different projects may use different tools or different versions/flavours of tools.
MBEP-CFG-100; SpaceCreator shall provide the capability to configure each of the used external tool.; The method of configuration is not enforced. The intent of the requirement is to be able to access the configuration, whether it is a file, webpage or GUI, from within the SpaceCreator IDE.; 

Verification Tools (scripts)
MBEP-FUN-240; SpaceCreator shall support bi-directional test-requirement tracing via external verification tool.; Bi-directional traceability combines forward and backward traceability to provide a complete view, ensuring full coverage and relevance.; 
MBEP-FUN-250; SpaceCreator shall support test coverage analysis of the implementation code via external verification tool.; ; 
MBEP-FUN-260; SpaceCreator shall support the execution of static analysis verification through external verification tool.; ; 
MBEP-FUN-270; SpaceCreator shall support the execution of static analysis verification of adherence to code style and formatting rules.; Code style rules are consistent use of indentation and spacing and proper naming conventions for variables, functions, methods and classes. The set of applicable rules may be configured in the external tool and be project specific.; 
MBEP-FUN-280; SpaceCreator shall support the execution of static analysis verification of code quality metrics.; Code quality metrics are e.g.,: lines of code, dead code detection, function/method length analysis, duplicate code detection, detection of deep nested blocks. The set of applicable metrics may be configured in the external tool and be project specific.; 
MBEP-FUN-290; SpaceCreator shall support the execution of static analysis verification of code security rules.; Code security rules are e.g.,: insecure string operations and detection of potential buffer overflows. The set of applicable rules may be configured in the external tool and be project specific.; 
MBEP-FUN-300; SpaceCreator shall support the execution of static analysis verification of code best practices.; Code best practices are e.g.,: prohibition of magic number usage, use of constant variables where it is expected, requirement to initialize variables before use. The set of applicable rules may be configured in the external tool and be project specific.; 
MBEP-FUN-310; SpaceCreator shall support the calculation of stack usage for each sporadic and cyclic interface.; The stack usage should be calculated by the analysis of the resulting binary. It is assumed that an external tool will be launched from within SpaceCreator. It is possible that the estimate may be higher than the actual stack usage. It is possible that for some interfaces the stack usage calculation may fail (e.g., they use recursion or dynamic calls).; 
MBEP-FUN-320; SpaceCreator shall allow gathering of performance data through external verification tool.; ; 
MBEP-FUN-330; SpaceCreator shall support performance time profiling.; ; 
MBEP-FUN-340; SpaceCreator shall support performance call analysis.; ; 
MBEP-FUN-350; SpaceCreator shall support performance call counts analysis.; ; 

Checklists
MBEP-FUN-370; SpaceCreator shall have the capability to browse review checklists.; Checklist is a list of checks that should be performed during project development as a part of Product Quality Assurance/Verification and Validation activities. Each check includes an identifier, a question, the supporting evidence/note, and mark. Reference [RD1].; 
MBEP-FUN-380; SpaceCreator shall allow importing review checklists data.; ; 
MBEP-FUN-390; SpaceCreator shall allow editing of the supporting evidence and mark for each question.; Supporting evidence and mark are mutable data fields, see ISVV guidelines. Reference [RD1].; 
MBEP-FUN-400; SpaceCreator shall allow exporting the filled in checklists to an external file.; Proposed file formats are PDF and Excel.; SpaceCreator should create document file of checklist result that can be used as a draft deliverable for a project.
MBEP-IF-10; SpaceCreator shall present checklist divided into categories; The categories are Req, AD, DD, SUM, Code, Validation; 
MBEP-CFG-110; The review checklist data shall at a minimum include questions and question identifiers.; Identifier and question are immutable data fields, see ISVV guidelines. Reference [RD1].;
